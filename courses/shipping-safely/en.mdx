Many outages don't start with a bug. They start with a deploy: new instances receive traffic before they are ready, old ones are killed in the middle of requests, a feature goes live for everyone at once, or a migration locks a table.

This course covers the four habits that make deploys boring. **Health checks** tell the platform when an instance can take traffic. **Graceful shutdown** lets old instances finish their work before they stop. **Feature flags** separate deploying code from releasing it. **Expand and contract** changes the database in steps that never break the running version.

The examples use Node.js, Docker and Kubernetes, but the same ideas apply on any platform with a load balancer.
