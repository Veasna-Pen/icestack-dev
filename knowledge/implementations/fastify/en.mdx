Production patterns for Fastify v5 on Node.js 22+. Focuses on low-overhead routing, Undici connection pool timeouts, lifecycle hook idempotency, distributed rate limiting, and zero-downtime graceful shutdown.

## Timeouts first

Fastify sets server-side connection and keep-alive limits, while outbound HTTP calls use Node.js's high-speed `undici` client with strict dispatch deadlines:

```ts
import Fastify from 'fastify';
import { request, Agent } from 'undici';

const fastify = Fastify({
  connectionTimeout: 5000,
  keepAliveTimeout: 5000,
  requestTimeout: 10000 // Total inbound request processing deadline
});

// Outbound Undici dispatcher with granular timeouts
const dispatcher = new Agent({
  connect: { timeout: 1500 },
  headersTimeout: 2000,
  bodyTimeout: 2000
});

fastify.get('/rates', async (req, reply) => {
  try {
    const { statusCode, body } = await request('https://api.example.com/rates', {
      dispatcher,
      signal: AbortSignal.timeout(2500)
    });

    if (statusCode !== 200) {
      return reply.code(502).send({ error: `Upstream HTTP ${statusCode}` });
    }

    const data = await body.json();
    return reply.send(data);
  } catch (err: any) {
    if (err.name === 'TimeoutError') {
      return reply.code(504).send({ error: 'Gateway timeout contacting rates provider' });
    }
    throw err;
  }
});
```

## Retry with backoff

Retry transient network drops and 5xx responses using exponential backoff with full jitter:

```ts
import { request } from 'undici';

const TRANSIENT_CODES = new Set([408, 429, 500, 502, 503, 504]);

export async function fetchWithRetry<T>(url: string, maxRetries = 3): Promise<T> {
  let attempt = 0;
  while (attempt < maxRetries) {
    attempt++;
    try {
      const res = await request(url, { signal: AbortSignal.timeout(2000) });
      if (!TRANSIENT_CODES.has(res.statusCode)) {
        return (await res.body.json()) as T;
      }
      if (attempt === maxRetries) {
        throw new Error(`Upstream failed with status ${res.statusCode} after ${attempt} attempts`);
      }
    } catch (err: any) {
      if (attempt === maxRetries || (err.name !== 'TimeoutError' && err.code !== 'UND_ERR_CONNECT_TIMEOUT')) {
        throw err;
      }
    }

    // Exponential delay with jitter
    const delay = Math.random() * Math.min(2000, 100 * 2 ** (attempt - 1));
    await new Promise(resolve => setTimeout(resolve, delay));
  }
  throw new Error('Unreachable');
}
```

## Idempotency keys via Fastify hooks

Use Fastify's `preHandler` and `onSend` lifecycle hooks to enforce at-most-once semantics:

```ts
import { FastifyPluginAsync } from 'fastify';
import fp from 'fastify-plugin';

export const idempotencyPlugin: FastifyPluginAsync = fp(async (fastify) => {
  fastify.addHook('preHandler', async (request, reply) => {
    if (request.method !== 'POST') return;

    const key = request.headers['idempotency-key'] as string;
    if (!key) return;

    // Check Redis for cached response or in-progress lock
    const cached = await fastify.redis.get(`idempotency:${key}`);
    if (cached) {
      if (cached === 'IN_FLIGHT') {
        return reply.code(409).send({ error: 'Request currently processing' });
      }
      const { status, body } = JSON.parse(cached);
      return reply.code(status).send(body);
    }

    // Claim key with 120s TTL
    const acquired = await fastify.redis.set(`idempotency:${key}`, 'IN_FLIGHT', 'EX', 120, 'NX');
    if (!acquired) {
      return reply.code(409).send({ error: 'Concurrent duplicate request' });
    }

    // Attach key to request context for onSend hook
    (request as any).idempotencyKey = key;
  });

  fastify.addHook('onSend', async (request, reply, payload) => {
    const key = (request as any).idempotencyKey;
    if (key && reply.statusCode >= 200 && reply.statusCode < 300) {
      const record = JSON.stringify({ status: reply.statusCode, body: JSON.parse(payload as string) });
      await fastify.redis.set(`idempotency:${key}`, record, 'EX', 86400); // 24h retention
    }
    return payload;
  });
});
```

## Rate limiting (`@fastify/rate-limit`)

Cluster-wide distributed rate limiting backed by Redis:

```ts
import rateLimit from '@fastify/rate-limit';

await fastify.register(rateLimit, {
  max: 100,
  timeWindow: '1 minute',
  redis: fastify.redis, // Shared Redis instance
  keyGenerator: (req) => (req.headers['x-api-key'] as string) || req.ip,
  errorResponseBuilder: (_req, context) => ({
    statusCode: 429,
    error: 'Too Many Requests',
    message: `Rate limit exceeded. Try again in ${Math.ceil(context.ttl / 1000)} seconds.`
  })
});
```

## Graceful shutdown

Trap OS signals (`SIGTERM`, `SIGINT`) to finish existing requests and cleanly close database pools:

```ts
const closeGracefully = async (signal: string) => {
  fastify.log.info(`Received ${signal}. Closing Fastify server cleanly...`);
  try {
    await fastify.close(); // Stops accepting connections and waits for active requests
    process.exit(0);
  } catch (err) {
    fastify.log.error(err, 'Error during shutdown');
    process.exit(1);
  }
};

process.on('SIGINT', () => closeGracefully('SIGINT'));
process.on('SIGTERM', () => closeGracefully('SIGTERM'));
```
